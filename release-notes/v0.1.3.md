# network-lab-vm 0.1.3 - versions AMD64 et ARM64

Cette préversion fournit les appliances VirtualBox AMD64 et ARM64 pour les laboratoires de réseautique de LOG100.

## Plateformes couvertes par cette préversion

L'appliance AMD64 est destinée aux systèmes suivants :

- Windows 10/11 sur processeur Intel ou AMD;
- Ubuntu x86_64;
- macOS sur processeur Intel.

L'appliance ARM64 est destinée aux systèmes macOS sur Apple Silicon.

Windows 11 sur ARM demeure une plateforme prise en charge en meilleur effort seulement.

## Configuration de la VM

- Ubuntu Server 26.04 LTS;
- 2 vCPU;
- 4 Gio de mémoire;
- disque dynamique de 24 Gio;
- Podman en mode rootless avec Netavark;
- outils réseau requis pour les laboratoires;
- Python 3 et outils usuels;
- serveur OpenSSH.

## Connexion SSH

Après l'importation et le démarrage de la VM :

```bash
ssh -p 2222 log100@localhost
```

Identifiants initiaux :

```text
Utilisateur : log100
Mot de passe : log100
```

La redirection SSH de VirtualBox est limitée à `127.0.0.1:2222` sur le système hôte.

## Utilisation des laboratoires

Les images de conteneurs des laboratoires ne sont pas préinstallées dans l'appliance. Les commandes `labctl` téléchargent les mêmes références d'images immuables depuis GHCR que sur les machines de l'ÉTS.

Le flux de travail normal reste :

```bash
./labctl doctor
./labctl up
./labctl check
./labctl submit
./labctl down
```

## Assets

- `log100-network-lab-vm-amd64.ova.gz` : appliance VirtualBox AMD64;
- `log100-network-lab-vm-amd64.ova.gz.sha256` : somme de contrôle SHA-256.
- `log100-network-lab-vm-arm64.ova.gz` : appliance VirtualBox ARM64;
- `log100-network-lab-vm-arm64.ova.gz.sha256` : somme de contrôle SHA-256.
